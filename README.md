# Send To PC — Windows

Companion program for the **Send To PC** Android app: barcodes and QR codes scanned on your phone are sent over your local Wi-Fi to this PC, copied to the clipboard and pasted into the active field.

**Download:** [Latest release → SendtoPC.exe](https://github.com/vistavio/SendToPC-download/releases/latest)

## Install
1. Download `SendtoPC.exe` from the latest release and double-click it.
2. If Windows SmartScreen shows "Windows protected your PC", click **More info → Run anyway** (the program is not code-signed yet).
3. Approve the administrator prompt. The program installs itself, adds a firewall rule for your local network and starts automatically with Windows.
4. A green barcode icon appears in the system tray. Right-click it → **Pair Phone**, and scan the QR code with the Send To PC app.

Requirements: Windows 10/11, phone and PC on the same Wi-Fi network.

Uninstall: run `Kaldir.bat` from the release (as administrator).

Privacy policy: https://vistavio.github.io/SendToPC-privacy/

# Send To PC — Windows (Türkçe)

**Send To PC** Android uygulamasının bilgisayar programı: telefonda okuttuğunuz barkod ve QR kodlar yerel Wi-Fi ağınız üzerinden bu bilgisayara gönderilir, panoya kopyalanır ve etkin alana yapıştırılır.

**İndir:** [Son sürüm → SendtoPC.exe](https://github.com/vistavio/SendToPC-download/releases/latest)

## Kurulum
1. Son sürümden `SendtoPC.exe` dosyasını indirip çift tıklayın.
2. Windows SmartScreen "Windows bilgisayarınızı korudu" uyarısı gösterirse **Ek bilgi → Yine de çalıştır**'a tıklayın (program henüz kod imzalı değildir).
3. Yönetici izni sorusunu onaylayın. Program kendini kurar, yerel ağ için güvenlik duvarı kuralı ekler ve Windows açılışında otomatik başlar.
4. Sistem tepsisinde yeşil bir barkod simgesi görünür. Sağ tıklayıp **Telefonu Eşle**'yi seçin ve QR kodu Send To PC uygulamasıyla okutun.

Gereksinimler: Windows 10/11, telefon ve bilgisayar aynı Wi-Fi ağında.

Kaldırma: Release'teki `Kaldir.bat` dosyasını (yönetici olarak) çalıştırın.

Gizlilik politikası: https://vistavio.github.io/SendToPC-privacy/
